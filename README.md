# Gravity Shift

중력을 뒤집어 적을 처치하고 탈출하는 2D 액션 로그라이크 프로토타입입니다. [기획서](docs/기획서.md)에 구역과 전투 규칙을 정리했습니다. [에셋 목록](docs/에셋-목록.md)에는 v0.2의 제작 항목과 규격을 정리했습니다.

## 실행

- **Unity 에디터**에서는 Unity Hub로 `GravityShift` 폴더를 엽니다. 에디터 버전은 **6000.6.10f1**입니다. `Assets/Scenes/GravityShift.unity`를 연 뒤 Play를 누릅니다.
- **Windows 빌드**는 에디터에서 **File → Build Profiles**를 열고 Windows 대상으로 빌드합니다. 출력 폴더를 `GravityShift/Build/Windows`로 지정한 뒤 `Gravity Shift.exe`를 실행합니다.
- **특정 시드**를 재현하려면 Main Camera의 Gravity Shift Game 컴포넌트에 있는 **Initial Seed**를 설정하거나, Windows 실행 파일에 `-seed 42`를 전달합니다. 기본값은 새 시드입니다.

## 조작

| 공통 | 키 |
|---|---|
| 이동 | A/D 또는 ←/→. 중력이 좌우로 작용하면 W/S 또는 ↑/↓ |
| 점프 | Space. 길게 누르면 더 높이 점프 |
| 대시 | Shift. 8방향이며 짧은 무적 |
| 근접 공격 | J |
| 스타일 전환 | Tab. 정신력은 유지되고, 잡기와 발판은 놓인다 |
| 일시정지 | Esc. 정지 중 R은 이 방, N은 새 런 |
| 방 재시작 | R. 사망·클리어 대기 중에도 이 방을 다시 연다 |
| 새 런 | N. 사망·클리어 대기 중에도 바로 새 시드 |

| 사이킥 | 엔지니어 |
|---|---|
| 좌클릭으로 대상 중력을 5초간 반전 | 좌클릭으로 중력 발판 설치 |
| 우클릭으로 잡고 버튼을 놓으면 던지기 | 마우스 휠 또는 Q로 설치 방향 회전 |
| F로 자신의 중력 반전 전환 | 우클릭으로 발판 제거, F로 설치된 발판 모두 반전 |

연구동, 마법탑, 궤도 정거장에는 각각 소개 방 하나와 시드로 생성하는 방 두 개가 있습니다. 생성 방은 시드에 따라 계단, 선반, 가시 틈 조각을 하나씩 넣을 수 있습니다. 워커와 앵커 외에 반전자가 나옵니다. 반전자는 2.4초마다 반경 4.5칸의 조작 가능한 중력을 1.1초 뒤집고, 0.45초 전에 링으로 예고합니다. 모든 적을 처치하면 출구가 열립니다. 다음 방에 들어갈 때 체력을 1 회복합니다. 사망하거나 마지막 방을 클리어하면 시드가 배너에 남고, 4초 뒤 또는 N으로 새 시드가 시작됩니다. 같은 시드는 같은 방과 같은 적 시작 방향을 만듭니다.

## Unity 코드

| 파일 | 역할 |
|---|---|
| `GravityShiftGame.cs`, `Controls.cs` | 60Hz 게임 루프, Unity Input System, 카메라 |
| `GameState.cs`, `Body.cs`, `Abilities.cs` | 방 진행, 중력·타일 충돌, 전투와 능력 |
| `RoomMap.cs`, `ZoneDefinition.cs`, `RoomGenerator.cs` | 타일 좌표, 소개 방, 시드 기반 방 생성 |
| `RoomView.cs`, `HudView.cs`, `Sfx.cs` | URP 2D 스프라이트, uGUI HUD, 합성 효과음 |

플레이하는 버전은 Unity다. 소스는 `GravityShift/Assets/GravityShift/Runtime`에 있다. 월드 단위는 타일 한 칸이며, 중력과 접촉 판정은 엔티티별로 적용한다. 방 배치는 Mulberry32로 시드를 재현한다. `src/`의 웹 프로토타입은 이전 버전 그대로 두며, 이 문서의 반전자·조각·일시정지와는 맞춰져 있지 않다.
