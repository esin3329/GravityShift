# 그래비티 시프트 (Gravity Shift) 기획서 v0.1

## 한 줄 소개
방마다 중력이 뒤틀리는 융합 차원에서 **중력 발판**과 **염동력**으로 중력을 지배하며 탈출하는 2D 사이드뷰 액션 로그라이크.

## 확정 사항
| 항목 | 결정 |
|---|---|
| 시점 | 2D 사이드뷰 |
| 1차 플랫폼 | 웹 (HTML5 Canvas, 순수 JS, 외부 라이브러리 없음) |
| 2차 플랫폼 | Unity 이식 (구조를 Unity 컴포넌트 방식에 맞춤, `README.md` 참고) |
| 세계관 | 연구소 + 마법탑 + 우주정거장 **세 가지 모두 사용** |

## 세계관: 차원 융합
중력 연구소의 실험 사고로 "중력 코어"가 폭주하면서 서로 다른 세 차원이 하나로 엉켜 붙었다.
- **구역 1 · 연구동**: 사고 현장. 중력은 정상(↓)이지만 곳곳이 불안정하다. (튜토리얼)
- **구역 2 · 마법탑**: 융합으로 끌려온 마법사의 탑. 중력이 거꾸로(↑) 흐른다.
- **구역 3 · 궤도 정거장**: 우주 정거장 잔해. 중력이 주기적으로 회전한다.
- **최종 구역 · 중력 코어**: 세 차원의 규칙이 동시에 섞인 곳. (예정)

구역마다 테마가 바뀌므로 세 세계관이 자연스럽게 공존하고, 구역이 진행될수록 **중력 규칙이 한 단계씩 복잡해진다** (정상 → 반전 → 회전 → 혼합).

## 핵심 규칙 (공통)
- 각 방에는 기본 중력 방향(↓↑←→)이 있다.
- 중력은 플레이어, 적, 상자 **모두에게** 똑같이 작용한다.
- 주 공격 수단은 **낙하 충격**: 높은 곳에서 떨어지거나 벽에 세게 부딪힌 적은 피해를 입는다. 가시에 닿은 적은 즉사.
- 빠르게 날아가는 물체(상자, 적)가 다른 적과 부딪혀도 피해.
- 기본기: 이동, 점프, 대시, 근접 공격(넉백).

## 플레이 스타일
| | 🟪 사이킥 (염동력) | 🟩 엔지니어 (발판) |
|---|---|---|
| 조작 대상 | 대상 하나 | 중력 빔 (폭 3칸, 중력 축을 따라 벽까지) |
| 리소스 | 정신력 게이지 (자연 회복) | 발판 최대 3개 (초과 시 가장 오래된 것 제거) |
| 스킬 1 | 좌클릭: 대상 중력 반전 (5초) | 좌클릭: 선택 방향 중력 발판 설치 |
| 스킬 2 | 우클릭 홀드: 잡기 → 놓으면 던지기 | 휠/Q: 방향 회전, 우클릭: 제거 |
| 스킬 3 | F: 자신의 중력 반전 (토글) | F: 모든 발판 방향 반전 (콤보용) |
| 감각 | 즉흥, 순발력 | 설계, 함정 |

- 중력 우선순위: **개별 반전(사이킥) > 발판 구역 > 방 기본 중력**
- **앵커** 적은 중력 조작이 통하지 않는다 → 근접 공격이나 던진 상자로 처리.

## 런 구조 (목표)
시작 시 스타일 선택 → 구역 1~3 (각 6~8방 + 미니보스) → 중력 코어 보스.
사망 시 처음부터 다시 시작, 연구 데이터로 영구 해금(새 모듈, 시작 옵션).

### 모듈 시스템 (예정)
런 중 획득하는 강화. 다른 스타일의 모듈도 얻을 수 있어 **혼합 빌드**가 가능.
- 무중력 지대(발판) + 던지기(염동력) → 던진 물체가 감속 없이 직진
- 중력 우물(발판) + 잡기(염동력) → 모인 적을 한 번에 들어 던짐
- 한 스타일만 고집하면 **각성 스킬** 해금 → 특화 vs 혼합 고민

## 절차적 방 생성
1. **중력 ↓ 기준으로 생성**: 바닥 둔덕 → 바닥 가시 구덩이 → 발판 3단(세로 3칸 간격 = 점프 높이) → 천장 가시 띠 → (정거장) 벽 가시 → 출구
2. **도달 가능 검사**: 서 있을 수 있는 칸을 노드로 걷기, 낙하, 점프 BFS. 대시와 중력 조작은 계산에서 빼서 보수적으로 판정한다.
3. **배치**: 적은 시작 지점에서 8칸 이상 떨어진 곳에, 앵커는 근접 공격이 닿는 바닥 근처에만 둔다.
4. **변환**: 마법탑은 상하 반전(중력 ↑), 모든 방은 50% 확률로 좌우 반전한다.
5. 실패하면 최대 60회 다시 시도하고, 그래도 안 되면 소개 방으로 대체한다. (300런 테스트에서 실패 0회, 런당 약 0.6ms)

| 앵커 | 0 | 0 | 1 | 1 | 1 | 2 |
