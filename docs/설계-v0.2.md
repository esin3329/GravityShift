# Gravity Shift 설계 v0.2

v0.1 시뮬 위에 얹는 확정안. 구현 대상은 Unity `GravityShift/Assets/GravityShift/Runtime`뿐이다. `src/` 웹 프로토타입은 더 이상 고치지 않으며, v0.2 규칙과 맞춰져 있지 않다. 생성 시드를 쓰는 난수 순서가 바뀌므로, 예전 시드의 방 배치는 재현되지 않는다.

## 반전자

- 맵 문자 `I`. 적이다. 체력 3, 조작 가능(앵커가 아님), 이동 55px/s, 가속 700.
- 순찰·추격은 워커와 같다. 스폰 직후 기절 2초도 같다.
- 펄스 타이머 초기값 2초. 기절·잡기 중에도 감소한다. 0 이하이고 기절이 끝났고 잡히지 않았을 때만 발동하고, 타이머를 2.4초로 되돌린다.
- 발동: 중심 거리 4.5타일 안의 조작 가능한 몸(플레이어 포함, 자기 자신 제외, 앵커 제외)의 개별 중력을 현재 중력의 반대(2스텝)로 1.1초 덮어쓴다. 사이킥 자가 반전도 이 시간 동안 끊긴다.
- 타이머가 0.45초 이하이면 위험 반경이 보이는 예고 링을 그린다.
- 배치: 앵커 다음, 워커 앞. 분리 거리 4. 자리가 없으면 그 마리는 건너뛰고 방 생성은 실패시키지 않는다.
- 마리 수: 난이도 0–1은 0, 2–4는 1, 5는 2.
- 소개 방: 연구동은 없음. 마법탑 소개는 오른쪽 워커 한 마리를 `I`로 바꾼다. 정거장 소개는 중앙 발판의 왼쪽 워커를 `I`로 바꾼다.

## 방 조각

`layout` 끝, 출구를 찍기 전에 한 번:

1. 확률 0.65가 아니면 난수를 더 쓰지 않는다.
2. 쓰면 조각 인덱스 `int(0, 2)`, `y0 = int(3, FLOOR - 4)`, `x0 = int(3, COLS - 3 - 6)`.
3. 6×4 칸이 전부 `.`이고 시작 열·출구 열을 안 밟을 때만 덮어쓴다. 실패해도 난수는 이미 소비된 상태 그대로 둔다.

조각 세 개, 위쪽이 0행:

```
......    ......    ......
.....#    .####.    ......
...##.    ......    #^^..#
.##...    ......    ......
```

도달 가능 검사는 조각이 들어간 뒤에 한다. 막히면 기존처럼 재시도한다.
적 후보는 시작점 BFS가 도달한 보행 칸만 사용하며, 후보 수 변화로 난수 소비 순서와 기존 시드의 방 배치가 달라진다.


## 시드 방향

적(워커, 앵커, 반전자)의 시작 방향은 `Math.random` / `UnityEngine.Random`을 쓰지 않는다. 생성 순서의 인덱스는 워커, 앵커, 반전자. 상자는 포함하지 않는다.

```
mixed = seed XOR uint32((roomIndex + 1) * 747796405 + bodyIndex * 2891336453)
facing = mulberry32(mixed) < 0.5 ? +1 : -1
```

플레이어 방향은 항상 +1.

## 손맛과 입력

- 피해가 들어가면 시뮬만 0.06초 멈춘다. `timeScale`은 쓰지 않는다. 이 게임은 자체 60Hz 루프라서, 멈추는 동안 파티클과 화면은 계속 그린다. 이미 멈추는 중이면 연장하지 않는다.
- 착지하는 프레임에 세로 스케일 0.85에서 시작해 0.1초 동안 돌아온다. 판정 크기는 그대로다.
- 공격 표시는 현재 스타일 색.
- Tab으로 스타일을 바꿔도 정신력은 유지한다. 잡기는 놓고, 발판은 지우고, 플레이어의 개별 중력은 끈다. 방 입장 때는 정신력을 가득 채운다.
- 잡기 실패 문구는 조작 불가면 `무효`, 정신력 부족이면 `정신력 부족`.
- Esc는 일시정지. 일시정지 중 R은 이 방, N은 새 런.
- 사망·클리어 대기 중에도 N은 새 런, R은 이번 방 재시작. 배너에 시드와 방 번호를 남긴다. 사망 대기는 4초.
- 엔지니어 칸은 설치된 개수만큼 밝다.

## 소리

에셋 없이 합성한다. 피격 블립, 피격당한 플레이어, 스타일 전환 클릭, 출구·사망·클리어 스팅, 반전 펄스, 작은 브라운 노이즈 루프. Unity는 소스 볼륨만 두고 믹서는 만들지 않는다.

## 그림

색 `#ff8a3d`는 반전자, `#070b10`은 외곽. 팔레트에 넣고 일회용 색을 늘리지 않는다. 적에게는 발, 앵커 고리, 플레이어를 보는 눈동자, 기절 표시가 있다.

## 일부러 안 하는 것

타이틀 화면은 두지 않는다. 프로토타입은 켜면 바로 플레이한다. 모듈, 보스, 무게추, 부유체, 좌우 중력 방은 이번 범위 밖이다. 방은 30×17이라 90도 회전이 들어가지 않는다.
