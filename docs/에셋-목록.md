# 에셋 목록과 제작 기준

Gravity Shift v0.2의 제작 항목과 목표 규격입니다. **필수 20 + 권장 20 + 추후 9 = 총 49개 항목/세트**이며, 파일이나 개별 스프라이트 프레임 수를 뜻하지 않습니다. 기재된 크기는 제작 목표이고, `제안`·`권장`·`선택` 표시는 확정 규격이 아닙니다.

## 공통 제작 기준

- 기본 타일은 32px, 방은 30×17타일, 기준 해상도는 960×544px입니다.
- 스프라이트는 투명 PNG, Point 필터링, 밉맵 끔, 기본 32 PPU를 목표로 합니다. 작은 스프라이트는 무압축을 권장합니다.
- 코드 틴트 대상은 무채색 명암으로 제작합니다. 상자·타일·배경은 고유색을 사용합니다.
- 중력 방향별 재사용은 회전을 기본으로 합니다.
- 막대와 조준 괄호는 코드 그래픽으로 유지합니다. 작은 파티클·화살표·염동 줄은 최종 화면에서 판독성을 확인합니다.
- 합성으로 유지할 수 있는 효과음은 피격·피해·클릭·반전 펄스·환경음입니다. 출구 개방·사망·클리어 스팅은 각각 분리하는 편을 권장합니다.
